# Artisan Commands

Все команды `php artisan` проекта с описанием.

---

## Основные

| Команда | Описание |
|---------|----------|
| `about` | Отображает базовую информацию о приложении |
| `clear-compiled` | Удаляет скомпилированный файл классов |
| `completion` | Генерирует скрипт автодополнения оболочки |
| `db` | Запускает новую сессию CLI базы данных |
| `dev` | Запускает сервисы разработки |
| `docs` | Открывает документацию Laravel |
| `down` | Переводит приложение в режим обслуживания / демонстрации |
| `env` | Отображает текущее окружение фреймворка |
| `help` | Отображает справку по команде |
| `inspire` | Выводит вдохновляющую цитату |
| `list` | Список всех доступных команд |
| `optimize` | Кэширует bootstrap, конфигурацию и метаданные фреймворка для повышения производительности |
| `pail` | Отслеживает логи приложения в реальном времени |
| `reload` | Перезагружает запущенные сервисы |
| `serve` | Запускает приложение на встроенном PHP-сервере разработки |
| `test` | Запускает тесты приложения |
| `tinker` | Интерактивная консоль для взаимодействия с приложением |
| `up` | Выводит приложение из режима обслуживания |

|---------|----------|
