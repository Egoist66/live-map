# Тарифы — как устроено ценообразование

> Источник правды по ценам: `config/plans.php` + оверрайды из админки
> «Payments» (`payment_items`, kind=plan_price). Меняешь в админке —
> приложение, бот и витрина подхватывают сами, без редеплоя.
> Стратегия заработка — в `monetization.md`.

## Модель: 3 + 1

Ставка — на ULove: свайпы, мэтчи и чат. Карта, лента, районы и бизнес
выключены по умолчанию и не являются частью бренда: пока модуль не
включён админом, в тарифах о нём ни слова (группы и строки
`usePlanDetails` помечены модулями и фильтруются в `showPlan()`).

| Тариф | Кому | Цена в месяц | Год | Неделя |
|---|---|---|---|---|
| Free | всем | бесплатно | — | — |
| PRO | персоны | $3.99/мес | $29.99 | $0.99 (только в момент азарта, в настройках не светить) |
| Premium | персоны (максимум для людей) | $7.99/мес | $59.99 | — |
| Business | только организации (кабинет компании) | $19.99/мес | — | — |

Цена одна для всех стран, без региональных tiers.

Почему так (конкуренты-2026: Tinder Plus ~$24.99, Gold ~$39.99,
Hinge+ ~$32.99, Bumble Premium ~$39.99):

- Мы новички без их бренда — бьём ценой в 5–6 раз ниже и локальностью
  («соседи рядом», а не паспорт по миру). PRO $3.99 даёт то, за чем идут
  в Gold за $39.99: кто лайкнул, невидимка, безлимитные возвраты и сброс.
- PRO — дейтинг-сила: 20 сообщений без мэтча, избранное 10, сброс/откаты
  безлимит, суперлайки 5/день, кто лайкнул, гости-уведомления, невидимка,
  инкогнито, скрытие имени/возраста, галерея 10.
- Premium — максимум: всё из PRO + гости с анкетами и «Написать»,
  CSV-статистика, избранное 15, галерея 15. Карта сверху: пины без срока,
  50 км (когда модуль включён).
- Free закрывает ~95% жизни и не урезается: свайпы безлимит, 3 сообщения
  без мэтча, избранное 3, сброс 1 раз, суперлайк/откат 1 в день, галерея 5.
  Смена почты и закрепы чатов — бесплатно всем (гигиена, не товар).

## Админка «Payments» (таб только для полных админов)

- **Тарифы** — карточки поверх конфига: название и описание правятся
  в карточке (`payment_items`, kind=plan_meta, `PUT plan-meta`), цены —
  пустое поле = цена из `config/plans.php` (`PUT plan-prices`, `null` =
  откат). Сохранение сбрасывает кэш (`PlanCatalog::bustPriceCache`),
  фронт и бот видят новое сразу. Клик по тарифу раскрывает вложенный
  список «что входит» (фишки с `payload.plan`): добавить внутрь тарифа,
  поправить, удалить, показать/скрыть.
- **Витрина** — таблица `payment_items` (служебные kind=plan_price/plan_meta
  скрыты): пакеты кредитов и реклама по модулям. Колонки: товар, цена,
  в продаже. У позиции бывает свой ценник под тариф (`payload.prices_by_plan`:
  free/pro/premium/business — пусто = базовая цена; считает `PlanCatalog::itemPrice`,
  фронт видит `price_for_plan` под свой тариф). Выключенное не продаётся
  и не светится в каталоге. Добавление/правка/удаление — из таблицы,
  удаление с подтверждением. Правка не трёт прочие данные (`payload`
  хранится и возвращается целиком).
- **Каталог фронта** (`GET /api/subscription/plans`) — динамический:
  на каждый тариф отдаёт итоговые `prices` (мес/год/неделя) и
  `features` (активные фишки из админки). `usePlanDetails.showPlan`
  показывает живую группу «✨ Что входит» первой, запасные строки —
  только если в админке пусто.
- **Шлюзы** — статус-заглушка (карты, Apple Pay, Google Pay): точка
  подключения реальной оплаты. Пока шлюза нет, платные тарифы выдаются вручную.
- **Excel** — кнопки выгрузки и загрузки в шапке раздела (`GET/POST /api/admin/payments/export|import`,
  `maatwebsite/excel`): 4 листа — «Как пользоваться» (инструкция + легенда), «Тарифы» (месяц/год/неделя,
  одна цена для всех стран, цвет по тарифу, живые итоги COUNTIF), «Что входит» (фишки: да — зелёным,
  нет — красным, списки), «Витрина» (товары + цены по тарифам + служебный JSON). Серые «Ключи» позволяют
  загрузке обновлять строки, а не двоить. Галочка «Очистить» — полное восстановление после удаления всего.
- Сид стартовой витрины: `php artisan db:seed --class=PaymentItemSeeder`
  (идемпотентен, всё выключено до шлюза).

## Аудитории

- **Персоны (`account_type=person`): только free/pro/premium.** Business им
  недоступен везде: таб тарифа, `SubscriptionController::renew` (422),
  `AdminUserController::update` (422), бот (кнопка скрыта + гвард).
  У персоны с `plan=business` в базе `effectivePlan()` возвращает `premium`.
- **Организации (`role=organization` / `account_type=business`): только
  business** (+ free при отказе). Выдаётся автоматически (+30 дней).
- **Стафф (admin/moderator): всегда `premium`** через `effectivePlan()`.

## Где что лежит (чтобы не расползлось)

| Что | Где |
|---|---|
| Цены, аудитории, сроки, лимиты | `config/plans.php` (+ оверрайды `payment_items`) |
| Типизированный доступ бэка | `App\Services\PlanCatalog` (цены, аудитории, каталог, витрина) |
| Витрина и цены (бэк) | `App\Models\PaymentItem`, `AdminPaymentsController`, сид `PaymentItemSeeder` |
| Гейты лимитов | `App\Models\User` (пины, радиусы, фото, районы, закрепы), `App\Services\DatingService` (сообщения 3/20, избранное 3/10/15, сброс, суперлайки) |
| Выдача/смена тарифа | `SubscriptionController` (status/catalog/renew/cancel), `AdminUserController::update` |
| Понижение протухших | `DowngradeExpiredPlans` (`plans:downgrade-expired`, daily) |
| Каталог для фронта | `GET /api/subscription/plans` (своя аудитория + активная витрина) |
| Цены на фронте | `usePlansCatalog` (синглтон, фолбэки = конфиг) → `usePlanSwitch`, `useSubscriptionRenewal`, `usePlanDetails.showPlan` |
| Тексты «что входит» | `usePlanDetails.PLAN_DETAILS` (строки с метками модулей, цены — запасные) |
| Админка | таб `payments` (`useAdminTabs`, `useStaffRole` — только админы, `useAdminLayout`), хук `useAdminPayments`, `AdminPaymentsManager` (только PrimeVue) |
| FAQ и AI-гид | `useFaq` + `useModuleContent` (модульные дополнения) ↔ `AiKnowledgeSeeder` (перезапуск сидера) |
| Бот | `TelegramPlanPanel` (цены из `PlanCatalog`), `choosePlan` |

## Правила изменения

1. Смена цены — админка «Payments» (или `config/plans.php` для дефолта).
   Фолбэки в `usePlansCatalog` и `PlanCatalog::defaults` дублируют значения —
   проверить их тоже.
2. Новый лимит — в `User`/`DatingService` + зеркало в `config/plans.php` +
   строка в `usePlanDetails` (с меткой модуля!) + FAQ + сидер.
3. Новая позиция витрины — строкой в таблице Payments (модуль, вид, цена).
4. Новый платный гейт на старте — запрещён без данных: сначала воронка
   (`показ → клик → оплата → возврат через 7 дней`), free→pro норма 1–5%.
5. Business персонам не выдаём никогда. Про выключенные модули в тарифах
   не упоминаем (метки модулей в `usePlanDetails`).
6. После смены цен: обновить этот файл и dev-лог (Правило №9).
